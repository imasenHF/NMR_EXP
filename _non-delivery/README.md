# Non-delivery materials

This directory preserves independent research files that are not part of the
*200 and More NMR Experiments* static reader delivery.

Keep this directory outside the reader publication allowlist. Updating the
reader should synchronize only `assets/`, `data/`, `experiments/`, `shared/`,
`index.html`, `README.md`, `PACKAGE-MANIFEST.json`, `START_READING.cmd`, and
`serve.ps1`.
